AI가 제안하고, 사람이 검증하고, 데이터가 쌓이면서 점점 똑똑해지는 구조

전체 아키텍처
Layer 0 — Fail-safe
PLC 레벨, AI와 독립 작동
temp>35 → 강제환기  /  humidity>95 → 제습  /  CO2>1500 → 차단
AI 서버 다운돼도 독립 작동
▽
Layer 1 — 데이터
데이터 파이프라인
Priva 센서(Read Only) · 기상청 API · KAMIS API · 자체 DB(에너지/인건비/자재비)
전처리: 결측치 보간, 센서 드리프트 감지, 파생변수 자동 산출 (VPD / GDD / DLI / DIF / RTR)
▽
Layer 2 — AI 엔진
4개 엔진 병렬 운영
환경 제어 · 생육 예측 · 비전 AI · 수요/가격 예측
▽
Layer 3 — 백엔드
Python 백엔드
매출/비용 확정 계산 (LLM에 계산 절대 안 시킴) · 엔진 간 조율 로직 · Vision API Circuit Breaker
▽
Layer 4 — LLM
Claude API
JSON → 리포트 번역 (계산 금지, 번역만) · 엔지니어 용어 → 농부 용어 변환 · 이상 이벤트 없는 날은 호출 안 함
▽
Layer 5 — 검증 UI
재배사 대시보드
AI 제안 vs 현재 비교 · A/B 테스트 실적 · Ground Truth 입력 · 피드백 → DB → 모델 재학습
AI 엔진 4개
Engine 01
환경 제어
제어 우선순위: 온도 범위(생존) → VPD 최적화(생장) → 에너지 비용(경제)
단계적 도입: Rule-based → MPC → RL 어드바이저
적응형 제어 주기 (기본 30분, 고온 시 10분)
Engine 02
생육 예측
모델 전략: Baseline(이동평균) → Prophet(보조) → TimesFM(실험)
복잡한 모델이 baseline을 이기지 못하면 baseline 사용
필수 파생변수: VPD, GDD(누적), DLI(누적), DIF, RTR
Engine 03
비전 AI
YOLOv8: 4대 병해 특화 (잿빛곰팡이, 흰가루병, 총채벌레, 온실가루이)
SAM + CLIP: 라벨링 비용 1/3~1/5 절감
Vision API Circuit Breaker: 일 10장 한도, 12h 쿨타임
Engine 04
수요/가격 예측
Prophet + LightGBM 앙상블
KAMIS API + aT 반입량 + 기상 예보
유통사 납품 스케줄, 경매장 휴무일 반영
성공 / 실패 판단 기준
성공 지표
  • 재배사 Ground Truth 입력률 > 80%
  • AI 제안 채택률 > 50% (1작기 후)
  • A급 비율 향상 또는 폐기율 감소
  • 순수익 기준 baseline 대비 +5% 이상
실패 신호
  • 재배사가 대시보드를 안 봄
  • Ground Truth 입력률 < 30%
  • AI 제안을 매번 무시
  • → 기술 문제가 아니라 UX 문제 → UI 재설계
인프라 비용 요약
~150~200만
클라우드-엣지 이원화 아키텍처 — 학습은 AWS/GCP A100 스팟 (월 6~12만원), 추론은 엣지 Jetson Orin (80만원) + CPU, Claude API 연간 ~3,300원, GPT-4o Vision 월 ~5만원, 카메라 4대 + 방습 하우징 ~250만원 (초기 투자). 연간 총 운영비 ~150~200만원 (Priva 연동비 제외)
