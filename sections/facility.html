설비 관리체계
흩어진 온실 설비 유지보수 정보를 표준 데이터로 축적하고, 나아가 AI가 현장 대응을 돕는 체계를 구축한다. 담당: 김용찬 과장(설비·전기·에너지·공조).
진행 방향 — 3단계
STAGE 1 · 이력 표준화·축적 현재
보수·정비 기록을 하나의 표준 양식으로 남겨 재사용 가능한 자산으로.
· 표준 이력 카드(현상·원인·해결·난이도·부품·예방)
· 허브별(신평·하동·진주) 이슈 동일 양식 정리
· 이력 데이터 자산화
산출물 · 유지보수 이력 카드
STAGE 2 · 관리대장·매뉴얼
전체 설비를 목록·스펙으로 관리하고, 대응 매뉴얼을 정비.
· 전체 설비 목록·스펙 관리대장
· 기존·예상 이슈 포함 유지보수 매뉴얼
· 설비 개선·추가 이력 연계
산출물 · 관리대장 + 매뉴얼
STAGE 3 · AI 대응·확산
현장에서 물으면 AI가 과거 이력으로 즉시 대응을 안내, 전 지점 확산.
· 질의 → 대처법·사진·난이도·담당자 자동 안내
· 전문지식 없이 대응(안전·공구 교육만)
· 허브별 담당자 교육으로 확산
산출물 · AI 검색(RAG) 대응
담당 설비 이력 작성 · 김용찬 과장    연계 AI·검색 구성 · 김태우

발생 현상
인버터에서 과부하 알람 발생 → 차단기 개별 On/Off 점검 결과 3번 AHU Off 시 정상 작동 확인. (인버터 1·2번이 AHU 홀·짝수로 분리 설치)
점검 결과
결로에 의한 볼트·너트·케이스 부식 진행 → 조인트박스 제거 후 전선 직결. 모터 외관 이상 없음(내부 문제 추정). 사양 3P/380V/60Hz/0.59A = 실측 0.59A 정상.
원인 해결 과정
① 전원 차단(전압 0V 확인)  →  ② 조인트박스 조임 볼트 부식으로 분해 불가 → 강제 파손 후 제거  →  ③ 모터 해체·교체(고정 4Point) → 조인트박스 파손으로 직결 결선  →  ④ 케이스·덕트 장착 → 복전 380V → 소모전류 0.59A 정상 작동 확인
